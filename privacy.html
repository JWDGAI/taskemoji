Privacy policy

Last updated: October 2026

What taskemoji is

taskemoji is a small personal tool that edits Google Tasks. It runs as a Google Apps Script project inside its owner's own Google account. It is not a public service and has no servers, website accounts or database of its own.

Data it accesses

When the account owner approves it, taskemoji can view and manage Google Tasks in that account. In practice it reads:

  • the names of your task lists;
  • each task's title, due date, position in the list, completion state and, for subtasks, its parent.

It also asks for permission to create time-based triggers, so it can run on a schedule without being started by hand.

What it does with that data

It uses the data only to provide the features described on the home page: it edits task titles (adding emoji), changes due dates, reorders tasks within a list and, when two color markers in a list name conflict, edits that list's name. It does nothing else with your data.

What it stores

  • In Google Tasks: the changes above, made directly to your own tasks.
  • In the script's own storage: for each task, an internal ID with the date taskemoji first saw it, plus the time of its last run. Task titles are not stored there.
  • In execution logs: the Apps Script project keeps logs that can include task and list titles, for example when a title is changed. These logs live in the owner's Google account and are visible only to the owner.

Nothing is copied to any server outside Google.

Sharing

taskemoji does not sell, share, transfer or disclose your data to anyone. It does not use it for advertising or analytics, and no person reads it.

Your control

  • You can withdraw access at any time at myaccount.google.com/permissions.
  • Deleting the Apps Script project removes the script, its stored dates and its logs.
  • Changes already made to your tasks stay in Google Tasks until you edit or delete them.

Google API Services User Data Policy

taskemoji's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes to this policy

If the way taskemoji handles data changes, this page will be updated and the date above changed.
